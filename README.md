This is a custom firmware developed for MKS SERVO42D.
The code was based in the open source library SimpleFOC, but there are some changes, like using C instead of C++.

This is a preview, no full debug is done.

What is included:

- Current Controller.
- Velocity Controller.
- Position Controller.
- Profile Position Controller.
- Home using Current Controller.
- Home using Velocity Controller.
- Home Now: reset encoder in actual position.
